## Step 4 - Start with Sonnet

The actual "unit of account" is called "tokens", and this brings us back to the important point.  These aren't people, beware of anthropomorphism, they are statistical probabilities from a multiplied matrix - lots of linear algebra.  The don't "lie", they sometimes output untrue things.  They are not "psychopathic" - they have some statistical probability to imitate psychopathy.  

Anyway - suffice it to say that we want to start with the happy-go-lucky workhorse Sonnet - which also happens to be the cheapest model to use.  We will keep an eye on it, and make sure to give it good context to work with.

## Step 5 - The real power of Agents with "Code"

This is what this tutorial has been about - getting you this far, finally into "Claude Code" (or equivalent with your agent).  As you can see in the screenshot above, here I am working on a project with dozens if not hundreds of documents - we call these "context".

In the web ui - you can make a document, but in claude code you can review it over and over again, making minor changes and cross referencing it to other documents.  This particular project - DOESN'T EVEN HAVE CODE - yet it is strengthened 100 times over by using Claude Code over the web UI - the difference is that powerful.  

Which is why I made a tutorial - You can do this too - and its not "about" so-called "code".  

Join me as we continue this series into the different projects I am working on, using Github (or equivalent), and other tips and tricks for best managing these new cutting-edge tools of the mid 21st-century.
